##  Projeto em destaque: EcoCampus

O EcoCampus é um projeto desenvolvido em linguagem C com o objetivo de monitorar o consumo de água em diferentes locais de um campus.

O programa realiza:
- Leitura de informações armazenadas em arquivo `.txt`.
- Cálculo do consumo total e médio.
- Identificação do local com maior consumo.
- Verificação dos locais que ultrapassaram o limite recomendado.
- Geração de um relatório com os resultados.

Esse projeto foi uma oportunidade de praticar a leitura e escrita de arquivos, estruturas de repetição, condições e operações matemáticas.
